This folder includes native `ifc_lite` libraries.
The libraries are built for Windows, macOS, and Linux from a modified version of the [ifc-lite](https://github.com/LTplus-AG/ifc-lite) project.

- Original project: <https://github.com/LTplus-AG/ifc-lite>
- Modified source repository: <https://github.com/ab4d/ifc-lite>
- License: [Mozilla Public License, version 2.0](https://www.mozilla.org/MPL/2.0/) (**MPL-2.0**)

The modified source adds native interoperability support used by this project. The complete corresponding source code for the distributed native libraries, including the MPL-covered modifications, is available from the modified source repository above.
